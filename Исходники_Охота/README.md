# Исходники по предметной области «Охота», вариант 138

Здесь собраны копии SCs- и GWF-файлов из активной базы знаний NIKA. Подборка предназначена для просмотра и демонстрации лабораторных работ 1–3; она не синхронизируется автоматически с работающим проектом и не входит в загружаемый каталог базы знаний.

Для удобного просмотра в корне размещены сводные файлы:

- `subject_domain.scs` — определения 32 понятий из `concepts/` и пояснительные заметки из `definitions.scs`;
- `relations.scs` — полные определения 21 отношения из `relations/`.

Вложенные каталоги сохраняют исходное модульное разбиение: можно открыть как сводный файл целиком, так и отдельное определение. Сводные файлы предназначены для чтения; рабочая база NIKA использует модульные исходники из `knowledge-base/extra/hunting/`.

Всего в подборке 76 файлов SCs и 27 файлов GWF.

## Лабораторная 1 — предметная область

- `concepts/` — классы и понятия охоты и животных;
- `relations/` — определения отношений и их домены;
- `instances.scs` — экземпляры и связи между ними;
- `book_facts.scs` — факты о животных;
- `definitions.scs` — пояснительные заметки к объектам.

## Лабораторная 2 — классификация сообщений

- `message_classes/` — классы вопросов и сообщений;
- `entity_classification.scs` — категории сущностей и их связь с объектами базы;
- `messages.scs` — дополнительные описания сообщений.

Код Jev-адаптера и JSON-примеры находятся в соседнем каталоге проекта `jev-adapter/`.

## Лабораторная 3 — правила и ответы

- `logic_rules/` — GWF-правила;
- `phrases.scs` — SCs-шаблоны ответов;
- `rules.scs` — указатели на правила.

## Где лежат активные файлы

Рабочая база знаний NIKA находится в `../knowledge-base/extra/hunting/`. Код ЛР4 находится в `../problem-solver/py/modules/messageProcessingModule/HuntingKnowledgeAgent.py`. В этой подборке нет Python-кода: здесь представлены SCs/GWF-материалы для первых трёх лабораторных.
